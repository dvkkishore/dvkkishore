# Hi, I'm Kishore 👋

I'm a master's student in **Artificial Intelligence for Industrial Applications** at **OTH Amberg-Weiden, Germany**. I enjoy engineering systems that connect AI, practical software development, and thoughtful user experience.

I work across software development, machine learning, computer vision, and applied AI. My interests also include robotics and interdisciplinary product design.

## How I approach engineering

I aim to understand both the capabilities and the limitations of the tools I use. That includes validating assumptions, reviewing generated code, writing focused tests, and documenting what a prototype **does not** yet prove.

I'm especially interested in systems where intelligent software can make complicated workflows more accessible, understandable, and reliable.

## Other interests

UI/UX, web and mobile development, applied robotics, and exploring the intersection between software and product design.
